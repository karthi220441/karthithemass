Color Usage Guidelines

  • Primary (#0F4C75) - Main navigation, headers, accents
  • Secondary (#3282B8) - Buttons, secondary CTAs, highlights
  • Success (#22c55e) - Resolved cases, positive actions
  • Warning (#f59e0b) - In progress, pending verification
  • Danger (#ef4444) - Reported, urgent, alerts
  • Light (#f8fafc) - Backgrounds, cards

🗺️ Interactive Map Monitoring

Leaflet.js based color-coded complaint markers on OpenStreetMap

Map Features
  • Free Mapping - Uses OpenStreetMap (no API key required)
  • Color-Coded Markers - Status-based marker colors
  • Real-Time Updates - Live complaint location data
  • Filtering - Filter by district or status
  • Popups - Click markers to view details
  • Legend - Status legend with counts
Map Legend
Reported/Pending
New complaints requiring attention
In Progress

Resolved

Map Code Example

Initialize Leaflet Map:
// Initialize map let map = L.map('leaflet-map').setView([11.1271, 78.6569], 8); // Add OpenStreetMap tiles L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', { attribution: '© OpenStreetMap contributors', maxZoom: 19 }).addTo(map); // Add color-coded markers L.circleMarker([latitude, longitude], { radius: 8, fillColor: getMarkerColor(status), color: 'white', weight: 2, fillOpacity: 0.8 }).bindPopup(complaintInfo).addTo(map);

📱 Responsive Design

Mobile-first approach for all device sizes

Responsive Breakpoints

  • Mobile (< 576px) - Single column, simplified navigation
  • Tablet (576px - 768px) - 2 columns, optimized spacing
  • Desktop (768px - 1200px) - 3-4 columns, full features
  • Large (>1200px) - Maximum content width, enhanced layouts

Mobile Navigation
